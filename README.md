# Heart Disease and Stroke – Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a Heart Disease and Stroke dataset using Python. The analysis explores patient health attributes, identifies data patterns, examines relationships between health indicators, and investigates factors associated with heart disease status.

## Objectives

- Understand the structure and characteristics of the dataset.
- Identify and handle missing values and duplicate records.
- Perform statistical analysis of health-related attributes.
- Analyse distributions, patterns, and outliers.
- Explore relationships between health indicators and heart disease status.
- Generate meaningful insights through data visualizations.

## Technologies Used
